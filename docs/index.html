How to install

Choose your device. You can also open the full guide as a PDF. No Android TV, or installing is too hard? See our recommended devices.

  1. On the phone, open Chrome and go to tinyurl.com/2y669ug7, or scan the QR code above with the camera.
  2. If Chrome warns that the file might be harmful, tap Download anyway.
  3. When it finishes, tap Open. Or open the My Files app, go to Downloads and tap LiveTV.apk.
  4. If you see "your phone is not allowed to install unknown apps from this source", tap Settings, turn on Allow from this source, then press Back.
  5. Tap Install.
  6. If Google Play Protect blocks it, tap More details, then Install anyway.
  7. Tap Open. Cable TV is now in your app list.
  8. Tap Sign in with Google and pick your account. You only do this once.

TVs don't have a normal web browser, so you use the free Downloader app.

A. Install Downloader (one time only)

  1. On the TV home screen, open Search and search for Downloader. Install Downloader by AFTVnews (orange icon).

B. Allow Downloader to install apps (one time only)

  1. Open Settings › System › About.
  2. Press OK on Android TV OS build 7 times until you see "You are now a developer".
  3. Go back to Settings › Apps › Security & restrictions › Unknown sources.
  4. Turn on Downloader.
On some older Android TVs it is under Settings › Device Preferences › Security & restrictions › Unknown sources.

C. Download and install Cable TV

  1. Open Downloader. Allow it to access files if it asks.
  2. Type tinyurl.com/2y669ug7 in the box and press Go. If that fails, type the full link shown above.
  3. Wait for the download to reach about 22 MB, then press Install. If Play Protect warns you, choose Install anyway.
  4. Press Open, or Done and then Delete to remove the downloaded file.
  5. Cable TV shows a code. On your phone, scan the QR code or go to google.com/device, enter the code and pick your Google account. The TV carries on by itself.
  6. To pin Cable TV to the home screen, highlight it, hold OK and choose Add to favourites.

  2. Go to Settings › My Fire TV › Developer options › Install unknown apps and turn on Downloader. If Developer options is missing, open Settings › My Fire TV › About and press OK on your device name 7 times.
  3. Follow part C of the Google TV steps.
Cable TV works on Android 5.0 and newer. It does not work on iPhone, iPad, Apple TV, Roku, or Samsung and LG TVs that don't run Android. On those, you can watch on this website instead, or plug in our recommended device, the Onn Full HD stick (about $40).

"App not installed"

An older copy (before version 1.7.2) is on the device. Uninstall Cable TV once, then install again.

"There was a problem parsing the package"

The download was incomplete. Delete it and download again, checking it is about 22 MB. On a TV, try the full link.

A channel doesn't play

The broadcaster may be offline, or the channel only plays in its own country (marked Geo-blocked). Some channels play in the app but not in a web browser. In the app, Settings › Channel list › Working channels only hides channels that failed our daily check.

Blocked by Play Protect

Tap More details, then Install anyway. Cable TV isn't in the Play Store, so Google shows this warning for it.
