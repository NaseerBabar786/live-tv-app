Design your packages

Tick what each package gets, then press Save settings. Every package always has 1+List, full screen, favourites, channel numbers and search. Without All channels a package has only our own Bazaar channels (Bazaar TV, Cinema, Music, Hits, Kids, Sports, Travel, Comedy, Movies, Dramas, Cooking, Latest Movies, Teens). The app follows your ticks the next time each viewer opens it.

How it works

  • Packages off (the switch in Settings is unticked): every viewer has everything, like Platinum, for free. Nothing is locked.
  • Packages on: a viewer without a package has Free. Locked modes show a 🔒 and the package they need; picking one opens the packages screen in the app.
  • Free trial: a brand-new viewer gets everything (Platinum) for the trial days in Settings, counted from the day they first signed in. When the trial ends they drop to Free, unless you gave them a package. This is different from the Free package, which only has the basic modes and never ends.
  • Buying: in the app the viewer picks a package and a length and presses Ask. That sends you a message in ✉ Messages. You reply with how to pay, and once they've paid you give them the package below.
  • Ending: 5 days before a package (or the trial) ends, the viewer sees a reminder once a day with Renew and Message us buttons. When it ends they drop to Free, and for a week the app tells them it ended.
  • Renewing: giving the same package again adds the time after the current end date, so paying early loses nothing. Giving a different package starts it today.

Promotions

Run a sale for Christmas, Labour Day, Family Day, Halloween or any event. Each promotion has its own name, dates, price, length and features. Viewers see it in the app's packages screen only between its start and end dates and ask for it like any package; you can also give it to a viewer in the list below. Press Save promotions after changes.
