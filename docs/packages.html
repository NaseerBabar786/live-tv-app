Design your packages

Free is fixed: every viewer gets every feature, with only our own Bazaar channels, so there is nothing to tick for it. Gold has everything Free has (the greyed ticks) plus All channels when it is ticked; press Save settings. Without All channels a package has only our own Bazaar channels (Bazaar TV, Cinema, Music, Hits, Kids, Sports, Travel, Comedy, Movies, Dramas, Cooking, Latest Movies, Teens). The app follows your ticks the next time each viewer opens it.

How it works

  • Packages off (the switch in Settings is unticked): every viewer has everything, like Gold, for free. Nothing is locked.
  • Packages on: a viewer without a package has Free: every feature, but only our own Bazaar channels. Other channels show a 🔒; picking one opens the packages screen in the app.
  • Free trial: a brand-new viewer gets everything (Gold) for the trial days in Settings, counted from the day they first signed in. When the trial ends they drop to Free, unless you gave them a package. After the trial they keep every feature on Free, with only our own Bazaar channels.
  • Buying: in the app the viewer picks a package and a length and presses Ask. That sends you a message in ✉ Messages. You reply with how to pay, and once they've paid you give them the package below.
  • Ending: 5 days before a package (or the trial) ends, the viewer sees a reminder once a day with Renew and Message us buttons. When it ends they drop to Free, and for a week the app tells them it ended.
  • Renewing: giving the same package again adds the time after the current end date, so paying early loses nothing. Giving a different package starts it today.

Promotions

Run a sale for Christmas, Labour Day, Family Day, Halloween or any event. Each promotion has its own name, dates, price, length and features. Viewers see it in the app's packages screen only between its start and end dates and ask for it like any package; you can also give it to a viewer in the list below. Press Save promotions after changes.

Promo codes

Give someone a package for free with a code. Make a code here, send it to them, and they type it in the app: Settings › ⭐ Packages › Promo code. They get the package straight away. Each person can use a code only once, and nobody can use a code you haven't made. If they already have the same package, the code's time is added after it ends. Press Edit on a code to change what it's for, its package, its length or how many people can use it (up to 100,000, or No limit for a code that runs all the time, like a welcome offer); people who already used it keep what they got.
