# Notes for Claude

A small Android phone app for collecting work, ideas and voice notes for Claude, then sending
them all at once.

- **Work** and **Idea** notes are typed; the microphone records a **voice note** using the
  phone's own speech to text (English, Urdu, Hindi, Punjabi or the phone's language).
- Every note has a topic (Live TV, Website, …). Topics are edited in Settings.
- **Send to Claude** builds one message from the ticked notes, grouped by topic, copies it and
  opens Claude. A topic can have its own Claude project link, so its notes go to that project;
  without a link the message is shared to the Claude app.
- Sent notes move to the Sent list, where they can be sent again.
- Text shared from other apps is saved as an idea. The app updates itself from the fixed
  `claude-notes` GitHub release.
